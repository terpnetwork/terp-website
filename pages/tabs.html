Despite the name, TABS is not a message board. It is the on-chain name registry: a username that points at your wallet, which other apps can look up.

List your app

Eco reads its catalog from public/ecosystem.json in the terp-website repository. A merged pull request on that file is what puts a project on this page.

  1. Fork github.com/terpnetwork/terp-website and open public/ecosystem.json.
  2. Add one object to the projects array with at least id, title, summary, tags, status (live, beta, or soon), and a links entry pointing at your app or repo.
  3. Use an existing tag from filters.tags when it fits (accounts, nft, governance, zk, ibc, infra, agentic, defi). Set relevance as a number if you care about sort order; higher appears first.
  4. Open a pull request against main. Keep the description short: what the app does and the live URL.

Deployed CosmWasm contracts show under Resources → App state from the published chain address file after they are live on mainnet — that list is not edited in this JSON.

Edit file: github.com/terpnetwork/terp-website/edit/main/public/ecosystem.json. Wider contribution notes: docs.terp.network/resources/contribution.
